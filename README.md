# Library
A dynamic Library application built using HTML, CSS, and JavaScript.

This project was completed as part of The Odin Project – JavaScript Path, focusing on object constructors, DOM manipulation, and state-driven rendering.

[Live Preview](https://austinej101.github.io/Library/)

# Features
This application allows users to:

- Add new books via a form dialog

- Remove books from the library

- Toggle a book’s read status

- View books rendered dynamically in a table

- See an empty-state prompt when no books exist

The application uses an in-memory array called myLibrary as the single source of all the data and re-renders the DOM whenever the state changes.
